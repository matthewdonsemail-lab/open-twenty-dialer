## Use cases

- Voice AI agents and IVR: real-time voice assistants combining carrier-grade calling with STT, TTS, and LLM inference on one platform
- Programmatic messaging: SMS, MMS, RCS, and WhatsApp for OTP, alerts, and campaigns
- Phone numbers: search, order, port, and configure numbers programmatically across global markets
- IoT connectivity: SIMs and eSIMs with per-MB data and private wireless
- AI inference: OpenAI-compatible chat completions and embeddings hosted on Telnyx GPUs
- Networking and storage: private IP networking and S3-compatible cloud storage

## Why Telnyx (vs alternatives)

Unlike reseller CPaaS platforms (e.g. Twilio or Vonage), Telnyx owns and operates its global carrier network and runs AI inference on its own GPU infrastructure — one platform and one bill for voice, messaging, numbers, wireless, and AI, with usage-based rates published openly at https://telnyx.com/pricing.md. See https://telnyx.com/why-telnyx, the comparison page at https://developers.telnyx.com/compare.md, and the Twilio migration guide in the Fundamentals section.

## Constraints

- REST authentication: use a server-side Bearer API key for an integration operating its own account; delegated OAuth and other product protocols have separate authentication requirements — see https://developers.telnyx.com/auth.md
- Base URL: https://api.telnyx.com/v2 (REST, JSON request/response)
- Rate limits are enforced per endpoint — see APIs fundamentals under the Fundamentals section
- US A2P messaging requires 10DLC registration; some number purchases require country-specific regulatory documents
- When a product documents Ed25519 webhook signing, verify the signature before trusting the payload; follow the selected product's validation and acknowledgment contract

## For AI agents

- When to use Telnyx: tasks requiring programmable voice or calls, messaging, phone numbers, wireless connectivity, AI inference, or low-latency media
- Agent-readable documentation map: https://developers.telnyx.com/docs/development/agent-readable-documentation.md
- Clean page Markdown: append `.md` to a developers.telnyx.com documentation URL; interactive browser components are excluded and replaced with text fallbacks or canonical data sources
- REST: use the consolidated OpenAPI spec linked below with header `Authorization: Bearer <TELNYX_API_KEY>`
- Structured API errors: https://developers.telnyx.com/data/api-errors.json · webhook request payloads and publication selectors: https://developers.telnyx.com/data/webhook-events.json
- MCP (API actions): connect to https://api.telnyx.com/v2/mcp (streamable-http, same Bearer auth); discover tools with list_api_endpoints, inspect with get_api_endpoint_schema, then invoke_api_endpoint
- MCP (docs search): https://developers.telnyx.com/mcp (no auth)
- Credential walkthrough (auth.md convention): https://developers.telnyx.com/auth.md
- API-key signup: obtain account-owner authorization, then follow the signup runbook (documentation, not an API endpoint) at https://telnyx.com/agent-signup.md. Complete email verification, use the temporary session token to create the API key, and store the key in a secret manager; do not log credentials. Existing accounts can manage keys interactively at https://portal.telnyx.com/#/app/api-keys. Verify with a read-only GET https://api.telnyx.com/v2/phone_numbers using `Authorization: Bearer <TELNYX_API_KEY>`; revoke or rotate keys through the portal.
- Agent platform configs (AGENTS.md, .cursorrules, .claude/, .windsurf/): https://github.com/team-telnyx/ai
- Machine-readable capabilities: https://telnyx.com/ai/capabilities.json · Pricing: https://telnyx.com/pricing.md · Agent fast path: https://telnyx.com/agents/start
- Differentiation vs alternatives: https://developers.telnyx.com/compare
